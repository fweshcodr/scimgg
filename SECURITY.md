# Security policy

## Reporting a vulnerability

Report vulnerabilities privately: on the repository's **Security** tab, choose **Report a
vulnerability**. Do not open a public issue or pull request for one.

Say what an attacker could do, which file or feature is affected, and the steps or input that
reproduce it.

## Scope

The code in this repository, run as the [README](./README.md) documents, is in scope. Only the
`main` branch is supported; fixes land there.

Not security issues:

- **Inaccurate game mechanics.** Report them with the
  [mechanic form](https://github.com/scimgg/scimgg/issues/new?template=mechanic.yml).
- **Game content and other third-party material**, such as the game cache and anything generated
  from it. It is not ours to fix.
- **Vulnerabilities in a dependency**, unless the way this repository uses it makes them
  exploitable. Report the rest to the dependency.
